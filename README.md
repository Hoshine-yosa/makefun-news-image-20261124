Every headline comes from the verified stories of that day's news digest, and no event, number or quote is invented.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`. Two runs write byte-identical output. The image is a 1024×1024 PNG (291,943 bytes), drawn as an HTML page and screenshotted with headless Chromium.
